feat(catalogue): add Laverne Fearless; centre the reviews section on desktop

Laverne Fearless joins the catalogue (191 products, 30ml ₹729 so the size
ladder is 99 / 155 / 229 / 285 / 529 / 729).

Tags are taken from the reference data rather than guessed, per the new rule in
AGENTS.md. Fragrantica 403s bots, so the data came from its parfumistas.us
mirror: gender "Men | Women" -> Unisex; ordered main accords citrus >
white-floral > fresh-spicy > powdery > amber -> scent citrus,floral,fresh-spicy,
powdery,amber; the site's own "oriental floral" phrasing -> family
oriental,floral,citrus; the "when to wear it" vote split (Summer 40%, Spring
25%, Day 65%) -> season spring,summer and time day, with weather hot,mild
following from those buckets. Every value already existed in the catalogue
vocabulary, so the existing filter options still match the new card.

Bottle image is the official Laverne product shot, converted to a transparent
RGBA cutout with the same flood-fill/un-composite pipeline used for Wild Colt:
969x1000 canvas, bottle at 411x805, 4.2% of bottle pixels near the light
background and 4.3% near the dark one, so it reads in both themes.

Parfumo has no Laverne Fearless page (404), so links go to Fragrantica plus the
official product page instead of the usual Fragrantica + Parfumo pair.

Also fixes the reviews heading not being centred on desktop. app.css sets
`.reviews-section{margin:32px auto;text-align:center;max-width:900px}`, but the
>=1024px block in desktop.css added `.reviews-section` to a
`{margin-left:0}` rule, killing the `auto` half of the centring and pinning the
900px block to the left edge. Measured in Chromium at 1440px: section centre
was 490px against a 720px viewport centre; it is now 720. Mobile at 390px was
and remains centred, so only the desktop override is touched.
